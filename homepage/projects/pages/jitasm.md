jitasm
===========

A x86-64 JIT assembler in Python.

## Install

```
pip install jitasm
```

## Download

[jitasm-py.tar.gz](https://raye.mistivia.com/releases/jitasm-py.tar.gz)

## Changelog

**2026-09-17**

Implemented the majority of AVX instructions related to single-precision floating point.

**2026-08-26**

Supported Windows.

**2026-08-25**

Implemented a basic subset of x86-64 that makes general-purpose programming reasonably convenient.
